# Enhancing Deep Learning-Based Sentiment Analysis Using Static and Contextual Language Models


## 📌 Overview
This repository presents my research paper on Deep Learning-based Sentiment Analysis using contextual and static language models.

## 📄 Paper
You can access the full paper here:
https://dergipark.org.tr/en/pub/bitlisfen/article/1288561

## 🧠 Summary
Research paper focused on Sentiment Analysis using Deep Learning and Natural Language Processing techniques. Proposed multi-layer CNN-based sentiment classification approaches utilizing both Static Language Models (Word2Vec, GloVe) and Contextual Language Models (ELMo, BERT) to analyze product reviews and user ratings. The study aimed to improve sentiment classification performance and evaluate rating consistency in large-scale review datasets. 
Technologies used: Python, NLP, Deep Learning, CNN, BERT, ELMo, Word2Vec, GloVe.
